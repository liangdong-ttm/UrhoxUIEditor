URHOX UI EDITOR

编辑你的游戏 UI

在浏览器里打开 UrhoX 项目，直接预览和调整 UI JSON。

怎么用

  1. 点击「打开项目」，选择包含 assets/ 的游戏工程目录。
  2. 在底部「UI 文档」中选择页面或模板，编辑后保存。
  3. 没有 UI JSON 时，把 AI Skill 交给你的 AI 自动转换和检查。

AI Skill

用于把 Lua UI 转成 `.ui.json`，检查缺图、重复 ID 和导出问题。
