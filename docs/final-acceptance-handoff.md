## 后续开发优先级

### P1：约束缩放，不再意外改写布局契约

位置：`src/input.js`、`src/doc.js`、`src/inspector.js`、`src/yoga-lite.js`。

问题：部分 resize 仍经 `applyWorldRect/applyRect` 固化尺寸及清理双边约束；
Flex、百分比、双边定位不能用普通绝对定位按钮的通过结果代替。

落地范围：

1. 区分自由绝对定位、百分比、左右/上下同时约束及 Flex 项，明确拖动每个手柄改变的字段。
2. 复用现有事务与单位解析，不新增平行布局模型；保留未操作轴和未操作节点的声明。
3. 对尚不能支持的组合明确禁用手柄并说明原因，不隐式切换定位模式。
4. 验收同一夹具在至少两种父容器尺寸下的结果，记录改动字段及世界矩形。
5. 覆盖撤销、重做、Escape、失焦、pointercancel、最小尺寸、锁定祖先。

完成标准：操作前后的布局契约可解释，撤销一次完整恢复；未操作字段不得无故被删除。

### P1：对齐、分布与层级命令的锁定/多选一致性

位置：`src/commands.js`、`src/preview.js`、`src/hotkeys.js`。

问题：对齐/分布仍用改变矩形的接口，尚未统一锁定祖先、父子选区和约束语义；
层级、显隐等命令还有主节点语义。不要假定复制/删除统一后所有命令都自动正确。

落地范围：

1. 对每个命令明确批量还是单选，工具栏、快捷键、命令校验使用同一规则。
2. 优先将纯位移操作接入已有移动约束路径，不用尺寸接口改写 width/height。
3. 锁定集合整体拒绝，或者有明确的可见过滤规则；禁止静默只处理部分节点。
4. 不将祖先和后代重复参与空间计算；无变化不增加历史。
5. 编组目前只支持同父绝对定位节点；多选解组、Flex 编组不能绕过保护直接上线。

完成标准：百分比/右下定位仍保持声明；锁定与父子选区夹具通过；
实际浏览器完成一次对齐、一次分布、撤销恢复。

### P1：补齐系统文件链路验收

位置：`src/editor.js`、`src/save.js`、`tests/project-session.test.js`。

问题：真实 OS 授权和写回未 GUI 验收；隐藏 `folderInput/filesFromInput` 仍有旧导入链路。

落地范围：

1. 先确认旧入口是否可达；可达则接入候选项目事务，不可达则在明确调用证据后清理。
2. 使用可丢弃工程，获得用户当次授权后验证成功保存、权限拒绝、文件丢失和保存中编辑。
3. 保存失败必须保留 dirty 和当前文档，不以只读预览服务作为替代目标。
4. 测试切换取消、坏 JSON、空工程、连续打开两个工程，以及迟到结果不覆盖新上下文。

完成标准：模拟测试和一次真实可丢弃工程的系统操作均有证据；不写 BikeKingBanana 真文件。

### P1：建立引擎对照夹具

位置：布局/绘制模块及真实游戏的只读调查记录。

问题：字体单位、主题默认值、变换、自绘、动态数据尚未证明与 UrhoX 一致。
JSON 静态预览也不等于 Lua 运行时构造的最终界面。

落地范围：

1. 固定同一 JSON、字体、分辨率、UI 缩放及引擎版本。
2. 采集引擎和编辑器的布局矩形、文字基线与截图，分别比较布局和绘制。
3. 第一批覆盖设置页、签到重复模板、资源条及九宫格弹窗。
4. 先确认每页权威数据来自 JSON 还是 Lua，不为让截图好看而修改游戏数据。
5. 预览样例数据与源 JSON 分离，不能执行任意 Lua 来“自动恢复运行态”。

完成标准：逐项说明差异来源和容忍阈值；没有对照证据的效果继续标未验收。

### P2：资源信息架构与错误可见性

位置：`src/assets.js`、`src/editor.js`、`src/style.css`。

待验收：目录导航、文件搜索、选择定位、缺图反馈、TGA 支持和 Inspector 字段拖入。
优先复用已有资源上下文与绑定机制；不要再造第二套缓存。

完成标准：缺图与仍在加载可区分；搜索/导航不丢失选图目标；切项目无旧缩略图回填；
不支持格式有可见诊断，不伪装为加载中。

### P2：复制、编组的高级语义

待定义：跨父粘贴的选区视觉关系、跨标签剪贴板、动态模板 ID/引用重映射、
非连续节点及不同 zIndex 的编组、带透明度/裁切/变换容器的解组。

当前取舍：绝对定位编组保留当前矩形，会固化选中节点的响应尺寸为像素；
静态副本名称防冲突不等于正确重映射游戏绑定。不要据此批量改 Lua 名称。

完成标准：先为每种操作写清视觉、层级和源数据契约，再添加反例测试；
不只测试节点数量变化。
